# Lingo Ecosystem Growth & Community Governance (Milestone 42)

## Architectural Proposals (Lingo RFCs)
All significant changes to language grammar, type semantics, runtime ABI, or the standard library proceed through a structured Request For Comments (RFC) process:
1. **Proposal Draft**: RFC markdown submitted to `docs/proposals/`.
2. **Community Review**: Discussion of alternatives, safety impact, and backward compatibility.
3. **Acceptance Gate**: Approved proposals transition into the roadmap with concrete test cases.
